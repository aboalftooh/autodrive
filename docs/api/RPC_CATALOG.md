## Coverage notes

- Dynamic gateway mappings were included; a literal-call regex alone would have missed seven command identifiers.
- `autodrive_send_chat_message_command_v1` remains reachable as compatibility/fallback for messages without `media_object_path`; v2 is used when the durable object path is present.
- Several older/direct auth/competition/chat/presence contracts are called by production Android code but their server function definitions are not present in the v73 repository. They are therefore **source-absent and runtime-unverified**, not silently inferred from old documentation.
- Repository SQL grants prove intended source configuration only, not live deployment.

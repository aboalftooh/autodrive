# Observability V11

## ما يُرسل إلى Crashlytics في Release

- سبب المزامنة وحالتها وزمنها.
- زمن كل مرحلة مزامنة ونجاحها أو فشلها.
- عدد عمليات Outbox: المعلقة، قيد المعالجة، وDead Letter.
- حالات Realtime وزمن إعادة الاتصال.
- نوع الخطأ وStack trace بعد إزالة الرسالة الأصلية.

## ما لا يُرسل

- OTP.
- FCM/Auth tokens.
- أرقام الهواتف والحسابات البنكية.
- المبالغ والأرصدة والعمولات.
- محتوى الرسائل أو الملاحظات أو Payloads.
- معرف المستخدم أو العميل.

## سياسة التسجيل

- Debug: Logcat بعد التنقية.
- Release: Crashlytics فقط للأحداث التشغيلية المنقّاة.
- لا يُكتب Crash dump محلي يحتوي تفاصيل حساسة.

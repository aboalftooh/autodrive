# Room Performance v10

## القرار

رُفعت قاعدة Room إلى النسخة 13، وأضيفت فهارس مبنية على استعلامات DAO الفعلية، لا على أسماء أعمدة عامة.

## العلاقات

لم تُضف `Foreign Key` بين الفواتير والمدفوعات أو المحادثات والرسائل؛ لأن كل Aggregate يُزامَن مستقلًا عبر Realtime، وقد يصل الطفل قبل الأب. فرض العلاقة محليًا قد يرفض حدثًا صحيحًا أو يكسر Offline-first.

تبقى العلاقات منطقية ومملوكة للمستودعات، وتُراجع Foreign Keys مجددًا فقط عند ضمان ترتيب إدخال Transactional واحد.

## حدود القوائم

- الإشعارات: آخر 50.
- حركات الرصيد: آخر 50.
- طلبات السحب: آخر 20.
- Outbox وDead letters: Batch محدود عبر `limit`.
- المحادثات والرسائل: لا يُفرض حذف أو قص تاريخ المستخدم؛ الاستعلامات أصبحت مغطاة بفهرس المالك مع الترتيب.

## التحقق

`tools/verify_room_v10.py` ينفذ Migration SQL الفعلية داخل SQLite، ويتحقق من حفظ الصفوف وإنشاء الفهارس وخطط `EXPLAIN QUERY PLAN`.
